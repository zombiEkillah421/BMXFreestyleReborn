# Changelog

## 0.1.0 — first UE5 source prototype

- Implemented original training area generated at runtime: curved ramps, banks, tabletop, ledge, rails, perimeter and light.
- Implemented arcade BMX pawn, riding, steering, jumps, landing tests, camera orbit, reset and bail recovery.
- Implemented 6 aerial trick actions, sequential combo queue and score multiplier.
- Added keyboard/gamepad bindings and immediate HUD with no external UMG assets.
- Added explicit warnings about missing Windows compilation/runtime QA.
